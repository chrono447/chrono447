✨ I work in **Natural Language Processing and Large Language Models**, with a focus on **Reinforcement Learning for LLMs**, also known as **LLM post-training**: teaching language models to reason and act better using rewards.

<br/>

## 🔍 What It Covers

| | |
|---|---|
| 🏆 **Reward models** | Learning from human preferences |
| 👥 **RLHF with PPO** | Training a model with human feedback |
| ⚖️ **DPO** | Learning directly from preference pairs |
| ✅ **GRPO & verifiable rewards** | Rewards that can be checked automatically, like a correct final answer |
| 🎭 **Reward hacking** | When a model exploits the reward instead of solving the task |
